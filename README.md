## 🚀 Featured Projects

### 🛰️ [Vigilant](https://github.com/Ali-3427/Vigilant)
Open-source intelligence analysis platform with a distributed data pipeline. Streams data through **Kafka**, caches with **Redis**, runs AI-driven processing, and deploys on **Kubernetes / Docker Compose**. MVP complete.

### ⚡ [ElektroPlan](https://github.com/Ali-3427/ElektroPlan)
Desktop engineering tool for **cable sizing, motor current, and voltage drop** calculations per **IEC 60364-5-52**. It is built to fail loudly rather than fall back on unverified values. Electron · TypeScript · Node.js · Apache 2.0.

### 🎯 SAR ATR *(in progress)*
Automatic target recognition on SAR imagery (MSTAR) using **ViT / Swin Transformer** and SARATR-X fine-tuning. Includes **Grad-CAM & Attention Rollout** explainability and **ONNX** edge deployment.

### ✈️ UAV Path Planning with Deep RL *(in progress)*
Autonomous UAV navigation via deep reinforcement learning with **Gymnasium + Stable-Baselines3**.

### 🔐 MCP Governance Control Plane *(in progress)*
Gateway for agentic AI. It intercepts **MCP tool calls** and enforces policy, human-in-the-loop approvals, and immutable audit logging.

### 📦 Flowork *(private)*
Work order & task tracking system with integrated stock management and **pattern-learning automatic material assignment**. Next.js · FastAPI · Docker.

### 📈 Smart Portfolio *(private)*
Django app generating BIST swing-trading signals (RSI, EMA, MACD, Bollinger) with a custom analysis engine and Claude API–powered market summaries.
